
# 📝 Text Summarizer Web App

A simple and interactive **Text Summarization Tool** built using HTML, CSS, and JavaScript. This web application allows users to input long text and get a short summary instantly.



## 🚀 Features

* ✍️ Paste or type any text
* ⚡ One-click summarization
* 🧠 Extractive summarization (based on sentence length)
* 🧹 Clear input and output easily
* 🎨 Clean and interactive user interface



## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript



## 📂 Project Structure


project-folder/
│── index.html
│── script.js
│── README.md



## ⚙️ How It Works

1. User enters text in the input box
2. The app splits the text into sentences
3. Sentences are sorted based on length
4. The top 2 longest sentences are selected
5. The summary is displayed on the screen



## ▶️ How to Run

1. Download or clone the repository
2. Open the project folder
3. Double-click `index.html`
   OR open with Live Server in VS Code


## 📸 Preview

Enter your text → Click **Summarize** → Get a short summary instantly.


## 📌 Example

**Input:**
Artificial Intelligence is transforming industries. It helps in automation and decision making. Many companies are investing in AI technologies.

**Output:**
Artificial Intelligence is transforming industries. Many companies are investing in AI technologies.
